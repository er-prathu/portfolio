    • PP—04Open source · live

      Prathamesh's Desk (this site)

      A portfolio you explore as a 3D desk: a working CRT television, live local weather in the window, and a contact form that really sends. Case study
      Problem
      A portfolio people remember, that is still fast, accessible and easy for recruiters to scan.
      What I built
      A three.js room rendered in the browser, with no build step. The TV's picture is a single GPU shader: curvature, scanlines, static and VHS tracking. Weather comes from Open-Meteo and drives rain, fog and snow outside. A Cloudflare Worker serves the site and sends contact messages through Resend, with validation, rate limiting and a honeypot. A text version is always one click away.
      Built with
      • three.js
      • GSAP
      • WebGL shaders
      • Web Audio
      • Cloudflare Workers
      • Resend
      • Node.js tests
